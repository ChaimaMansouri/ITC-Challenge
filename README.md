# 💡 InnovateHub

> Elegant platform created during the **ITC Challenge**, designed to help users discover company services and **book spaces, meeting rooms, or event halls** based on their needs.

---

### 💡 About the Project

**InnovateHub** is a modern business website developed during the **ITC Challenge**.  
It represents a company that provides professional services and offers flexible spaces for entrepreneurs, startups, and organizations to host **meetings, events, and workshops**.  
Users can explore services, view available halls, and book spaces based on **event type, number of people, and duration**.

---

### ✨ Features

- 🏢 Professional introduction to the company and its values  
- 📋 Clear presentation of services and facilities  
- 🗓️ Space booking system based on event type and number of attendees  
- 💼 Gallery of modern offices, halls, and workspaces  
- 📞 “Join Us Now” contact form for booking and inquiries  
- 🎨 Clean, responsive, and elegant design (HTML, CSS, JS)

---

### 🛠️ Technologies Used

- **HTML5**  
- **CSS3**  
- **JavaScript (ES6)**
